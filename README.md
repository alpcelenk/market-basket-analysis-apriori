# Market Basket Analysis using Apriori

## Project Overview

This project applies Association Rule Learning using the Apriori algorithm on a bakery sales dataset.

The main objective is to discover customer purchasing patterns and identify products that are frequently bought together.

---

## Technologies Used

- Python
- Pandas
- Apriori Algorithm
- Association Rule Learning
- Jupyter Notebook

---

## Dataset

The dataset contains bakery transaction records.

Each transaction represents a customer's basket and includes products purchased together.

---

## Metrics

### Support
Measures how frequently an itemset appears in the dataset.

### Confidence
Measures how often the rule has been found to be true.

### Lift
Measures the strength of the association between products.

- Lift > 1 indicates positive association
- Higher lift values indicate stronger relationships

---

## Example Insights

- Customers who buy hot chocolate often purchase cake as well.
- Customers purchasing coke are likely to buy sandwiches.
- Strong associations were found between salad-related products.

---

## Conclusion

This project demonstrates how Association Rule Learning can be used to analyze customer purchasing behavior and generate actionable business insights.

The extracted rules could be applied in:

- Recommendation systems
- Personalized marketing
- Product placement optimization
- Sales strategy development
